Hermes API

当前域名同时承载网站首页和 Hermes API。公开页面走静态网站，API 路径转发到本机 Hermes API Server。

GET https://xiejunjie.indevs.in/health POST https://xiejunjie.indevs.in/v1/chat/completions GET https://xiejunjie.indevs.in/v1/models

调用 API 时需要携带已配置的 API Key。健康检查无需认证。
